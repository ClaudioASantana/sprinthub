# Checklist · Definition of Done

Use este checklist antes de marcar uma story como pronta para revisão ou concluída.

## 1. Requisitos
- [ ] Os requisitos funcionais da story foram implementados
- [ ] Os critérios de aceite foram atendidos

## 2. Qualidade de código
- [ ] O código segue os padrões do projeto
- [ ] Estrutura, nomes e organização estão coerentes com o restante do código
- [ ] Não foram introduzidos segredos hardcoded
- [ ] Tratamento básico de erro foi considerado
- [ ] Não surgiram erros novos de lint
- [ ] Comentários foram adicionados apenas onde realmente ajudam

## 3. Testes
- [ ] Testes unitários necessários foram criados ou ajustados
- [ ] Testes de integração necessários foram criados ou ajustados
- [ ] Tudo que precisa passar foi executado com sucesso
- [ ] Não deixei testes quebrados ou pulados sem motivo registrado

## 4. Verificação funcional
- [ ] Eu validei o comportamento principal na prática
- [ ] Casos de erro e bordas importantes foram considerados

## 5. Administração da story
- [ ] Checklist técnico da story foi atualizado
- [ ] Arquivos alterados foram registrados
- [ ] Decisões tomadas durante a implementação foram anotadas
- [ ] Riscos, dívida ou follow-ups foram documentados

## 6. Build e configuração
- [ ] O projeto continua buildando corretamente
- [ ] Dependências novas, se existirem, foram justificadas
- [ ] Configurações ou variáveis novas foram documentadas

## 7. Documentação
- [ ] README foi atualizado, se necessário
- [ ] Documentação técnica foi atualizada, se necessário
- [ ] Mudanças de contrato ou uso foram registradas, se necessário

## Confirmação final
- [ ] Eu conseguiria entregar esta mudança para revisão sem precisar explicar oralmente o que ficou faltando
